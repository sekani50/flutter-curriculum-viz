## 01. Learning Objectives
*   Write basic Dart code (variables, functions, lists) using DartPad.
*   Understand Flutter's widget model (Everything is a Widget).
*   Build simple, beautiful UIs (BMI Calculator, Forms).
*   **Leverage AI tools (ChatGPT/Claude/GitHub Copilot) to boost developer productivity.**
*   Collaborate in teams to plan and build a project.
*   Troubleshoot IDE and environment setups.
*   Present a working mobile application.

## 04. Day-by-Day Journey

### Day 1: Foundations — Dart & Flutter Intro (DartPad)
*   **Session 1: Welcome & Intro to Dart**
    *   Getting started with DartPad.
    *   Variables, Data Types (String, int, double, bool).
    *   Basic Logic: if/else statements.
*   **Session 2: More Dart Fundamentals**
    *   Working with Lists and Maps.
    *   Loops and basic error handling.
    *   Introduction to Classes.
*   **Session 3: Introduction to Flutter**
    *   "Everything is a Widget" concept.
    *   Building basic layouts in DartPad (Text, Column, Row, Container).
    *   Understanding the Widget Tree.

### Day 2: UI Mastery & AI Productivity
*   **Session 1: Form Building**
    *   Input widgets: TextField, TextFormField.
    *   Buttons: ElevatedButton, TextButton.
    *   Form Validation basics.
*   **Session 2: BMI Calculator App**
    *   Building a simple BMI UI.
    *   Capturing Height/Weight, calculating, and showing results.
    *   Basic State management (setState).
*   **Session 3: AI for Developers & Group Planning**
    *   **Introduction to AI Tools:** Using AI to explain code, generate snippets, and debug.
    *   Dividing participants into groups.
    *   Brainstorming project ideas and creating a simple plan.

### Day 3: Project Phase — Build & Debug
*   **Session 1 & 2: Project Implementation**
    *   Creating the initial project structure.
    *   Starting the UI implementation based on the group plan.
*   **Session 3: Troubleshooting & IDE Setup**
    *   One-on-one assistance for IDE issues (VS Code, Flutter SDK).
    *   Debugging project-specific bugs.
    *   Attending to technical blockers.

### Day 4: Project Phase — Finalize & Polish
*   **Session 1 & 2: Advanced Features & Polish**
    *   Adding final screens and navigation.
    *   Improving UI/UX (Colors, Fonts, Spacing).
*   **Session 3: Presentation Prep & Debugging**
    *   Preparing the demo and presentation slides.
    *   Final round of IDE setup assistance.
    *   Ensuring the app runs on physical devices.

### Day 5: Graduation — Demo & Celebration
*   **Session 1: Project Presentations**
    *   Each group demos their app (5-7 mins).
    *   Q&A from facilitators and peers.
*   **Session 2: Merry Merry & Networking**
    *   Group photos and celebration.
    *   Networking and refreshments.
*   **Session 3: Certification & Closing**
    *   Sharing certificates of completion.
    *   Next steps and post-training resources.

## 05. Evaluation Criteria
*   **Functionality (40%):** Does the app work as intended?
*   **Design (30%):** Is the UI clean, and user-friendly?
*   **Teamwork (15%):** How well did the group collaborate?
*   **Presentation (15%):** Clarity and confidence during the demo.
