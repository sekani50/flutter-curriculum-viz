Training Philosophy

Getting Straight to Business

We want this programme to be exciting and practical. No boring long lectures—just hands-on building from Day 1.

🚀
Interactive Learning: Use DartPad for an instant start without setup hurdles.
🎨
UI First: Build beautiful, real-world UIs like BMI calculators and Forms.
🤝
Collaborative: Work in teams to build a project you're proud of.

Key Learning Outcomes

  • Master Dart fundamentals on DartPad.
  • Build multi-screen Flutter applications.
  • Handle user input and simple state.
  • Design premium, modern mobile UIs.
  • Collaborate using Git and GitHub.
  • Troubleshoot real-world development issues.
02

Prerequisites & Setup

Critical Setup Guides

Complete these steps before Day 1 to ensure a smooth start:

  • 🔗 1. Create a GitHub Account
  • 🔗 2. Install VS Code on Mac or Windows
  • 🔗 3. Install Flutter (2025 Guide)
  • 🔗 4. Install & Setup Android Studio (Emulators)
  • 🔗 5. Run App on Physical Phone

Training Requirement

We assume you have already installed GitHub and the required tools as instructed before the programme. Day 1 will focus on coding immediately.

Note: We will have technical support sessions on Day 3 & 4 for any remaining IDE issues.
